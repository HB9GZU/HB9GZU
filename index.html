Was ist hier real, was nicht?

Gesichts-/Hand-/Pose-Tracking läuft mit echten ML-Modellen (MediaPipe Tasks Vision) direkt im Browser. Sprache läuft über die native Web Speech API (Browser-ASR/TTS). Zusätzlich zum Regel-Responder gibt es jetzt lokale "Jarvis"-Skills (Uhrzeit, Datum, Website öffnen, Web-Suche, Wetter, Rechnen, Witze, Gedächtnis) — keine Cloud-KI ohne eigenen Server. Der Avatar ist ein stilisierter Cat-Bot, kein fotorealistisches Abbild. Details siehe README.
